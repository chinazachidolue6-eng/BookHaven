# 📚 BookHaven — Your Personal Book Discovery Space

BookHaven is a React-based book library application designed to help users discover books, explore different genres, and find their next favorite read.

The project was built to practice and strengthen my frontend development skills by creating an interactive, user-friendly application with functional search and category filtering.

## ✨ Features

* **📖 Book Collection:** Browse a collection of books displayed in an organized grid layout.
* **🔍 Search Functionality:** Search for books by title and find books more easily.
* **🏷️ Category Filtering:** Filter books by category to explore books that match your interests.
* **📚 Book Details:** Explore book information, including descriptions and other available details.
* **📱 Responsive Design:** A clean interface designed to provide a good browsing experience across different screen sizes.
* **🎨 Modern UI:** A visually appealing layout featuring a navigation bar, hero section, book cards, and category sections.

## 🛠️ Technologies Used

* **React.js** — Building reusable UI components and managing application state.
* **JavaScript (ES6+)** — Implementing interactive features and application logic.
* **HTML5** — Structuring the application.
* **CSS3** — Styling the interface and creating the layout.
* **Vite** — Development server and build tool.
* **Git & GitHub** — Version control and project hosting.

## 🚀 Getting Started

Follow these steps to run BookHaven on your local machine.

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm (included with Node.js)
* Git (optional, if you want to clone the repository)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/chinazachidolue6-eng/BookHaven
```

**2. Navigate to the project directory**

```bash
cd bookhaven
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
